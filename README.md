# CatShu Runner — Reference Demo

This is the implementation direction for the screenshot you supplied.

## What is playable
- 3 lanes
- left/right lane switching
- jump and slide
- moving coins
- barriers and trains
- collision / game over
- score, combo and coin HUD
- keyboard + touch controls
- rear-view CatShu runner
- generated CatShu world used as the visual reference

## Run
Open `index.html` directly in a browser, or upload the folder to GitHub Pages.

## Important
This is a real gameplay prototype, not a screenshot/video. The next production pass should replace the temporary generated runner sprite with a proper CatShu back-view sprite sheet and replace the simple collision objects with layered 3D assets.
