# CatShu Racing — Unity Starter

هذا Starter Project مخصص لبناء لعبة قيادة 3D بطابع CatShu.
الهدف من أول نسخة هو تثبيت نظام القيادة الحقيقي قبل إضافة المدينة والجراج والـNFTs.

## المطلوب
- Unity 6 (يفضل آخر LTS متاح لديك)
- افتح هذا المجلد كمشروع Unity

## تشغيل الـDemo
1. افتح المشروع.
2. من القائمة العلوية اختر:
   CatShu Racing > Create Driving Demo
3. سيتم إنشاء Scene باسم `CatShuDrivingDemo` وتشغيلها.
4. اضغط Play.

## التحكم
- W / Up: تسارع
- S / Down: فرامل / رجوع
- A / D: توجيه
- Space: Handbrake
- Left Shift: Nitro
- R: Reset
- C: تغيير الكاميرا

## الموجود في هذه المرحلة
- سيارة 3D يتم إنشاؤها تلقائياً من primitives.
- WheelColliders.
- تسارع وفرامل وتوجيه.
- Handbrake وDrift أساسي.
- Nitro.
- كاميرا Chase قابلة للتغيير.
- عداد سرعة.
- طريق تجريبي وحواجز وقفزات بسيطة.
- HUD.

## المرحلة التالية
هذه النسخة intentionally ليست الشكل النهائي للعبة.
بعد التأكد أن القيادة ممتعة، نستبدل الـplaceholder car بموديل CatShu Roadster حقيقي، ثم نبني:
- CatShu 3D driver
- مدينة مفتوحة
- Traffic
- Free Drive
- Races / Time Trials / Stunts
- Coins / Points / Missions
- Garage
- Upgrades
- Cars / Skins / Wheels / Nitro
- Web build للموقع

مهم: لا يوجد أي اعتماد على أصول Night City Racing. الهدف هو بناء لعبة CatShu أصلية بنفس نوع تجربة ألعاب القيادة 3D.
